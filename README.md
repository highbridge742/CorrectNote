# CorrectNote

誤字を気にせず、思考の速度でメモが取れることを目指した Windows 用のメモ帳です。再変換・簡易入力・自動補正などで、効率よく文字を打てるようにします。かな入力(JIS 配列)とローマ字入力のどちらにも対応しており、半角アルファベットの入力への対応も進めています。

左の欄に入力すると、右の欄に補正後のテキストが行ごとに対応して表示されます(入力欄と補正欄を1つにまとめたレイアウトにも切り替えられます)。

## 安全性について(いちばん大事なこと)

このアプリは**完全にオフラインで動作**します。

- **ネットワーク通信を行うコードが存在しません**。AI やクラウドへの送信は一切なく、入力した内容がパソコンの外に出ることはありません。ソースコードを検索して `socket` / `urllib` / `requests` などの通信モジュールが使われていないことを、誰でも確認できます。
- **データはすべてローカルの JSON ファイル**(exe と同じフォルダに作られる vocabulary.json など)に保存されます。メモの内容も語彙も、あなたのパソコンの中にだけあります。
- **グローバルキーボードフックを使いません**。ホットキーはアプリ自身のウィンドウ内でのみ動作する実装で、他のアプリの入力を監視することはありません。この設計はウイルス対策ソフトの誤検知も起こしにくくしています(同じ理由で、exe の圧縮に誤検知の原因となる UPX も使っていません)。
- 補正は**辞書(janome の形態素解析)とローカルの統計**だけで行います。機械学習モデルのダウンロードや外部 API の呼び出しはありません。

## 主な機能

- **再変換**: 確定済みの単語を、いつでも候補一覧から選び直せます。クリックのほか **F2** キーでも開け、押すたびに1つ左の語へ遡れるので、少し前に書いた語もスムーズに直せます。
- **簡易入力ウィンドウ**: **Ctrl+Insert** または **Ctrl+Shift+-** で、他のアプリを使っている最中でも小さな下書き窓を呼び出せます。閉じると内容が自動でクリップボードに入るのですぐ貼り付けられ、本体のメモ帳にも送られます。メモしたいことをその場で書き留めるのにも使えます。
- **自動補正**: 打ち間違いから正しい単語を推測して提案・補正します(直せる誤りの種類は下記)。
- **ブックマーク**: 行番号のダブルクリックで行に目印を付け、あとから順にたどれます。
- **引用モード**: メモの中にある単語をクリックで拾って、カーソル位置に差し込めます。もう一度打ち直す必要も、コピーして貼り付ける手間もありません。**F1**・選択なしの **Ctrl+C**・**=** のどれからでも入れます。
- **括弧で括る**: 選択した範囲をボタン1つで「」『』【】“” などの括弧で囲めます。
- **タブ管理と自動保存**: 複数のメモをタブで開けます。保存せずにそのまま閉じても、次に開いたときに続きから再開できます。

そのほか、検索・置換(正規表現対応)、ダークモード、直されたくない語の指定、語彙の手動登録などがあります。

## 自動補正で直せる誤りの種類

- 隣のキーの押し間違い
- 濁点・半濁点の付け忘れや余分
- 「ゃ」「っ」などの小書きの忘れ
- 1文字の打ち忘れ・キーの押しすぎ
- 打つ順番の入れ替わり
- 濁点だけが離れて入力されたもの
- 日本語入力をオフにしたまま打った行(かな入力・ローマ字入力とも、半角のまま打った内容を日本語に復元)

直すのは「明確に誤りだと言えるもの」だけです。判断がつかない場合はあえて直さず、色を付けて知らせるだけにとどめます。

## 使い方

### exe をそのまま使う

[Releases](../../releases) から `KanaMemo.exe` をダウンロードして、好きなフォルダに置いて実行するだけです。Python のインストールは不要です。語彙などのデータファイルは exe と同じフォルダに自動で作られます。

### ソースから実行する

Python 3.11 以降と tkinter(通常は Python に同梱)が必要です。

```
pip install janome
py app.py
```

janome は必須です(無いと補正の主力の守りが働かず、精度が大きく落ちます)。`py check_janome.py` で確認できます。

### 自分でビルドする

```
build_exe.bat
```

をダブルクリックすると `dist\KanaMemo.exe` ができます(内部で PyInstaller を使用)。GitHub Actions でも `v` で始まるタグを push すると自動でビルドされ、Release に exe が添付されます。

## テスト

```
py tests_mock.py
```

janome の無い環境用のモックテストです(900 件以上)。janome を入れた環境では一部が実機挙動側に寄って NG になりますが、それは想定どおりです。
