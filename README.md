# CorrectNote

誤字を気にせず、思考の速度でメモが取れることを目指した Windows 用のメモ帳です。再変換・簡易入力・自動補正などで、効率よく文字を打てるようにします。かな入力(JIS 配列)とローマ字入力のどちらにも対応しており、半角アルファベットの入力への対応も進めています。

左の欄に入力すると、右の欄に補正後のテキストが行ごとに対応して表示されます(入力欄と補正欄を1つにまとめたレイアウトにも切り替えられます)。

### v1.12.58

一括挿入、行に固定するルーラー、ボタンの表示・並べ替え、Undo／Redoの下線表示を追加しました。簡易入力への選択文字の取り込み、単語帳の独立したウインドウ操作、解析の進み具合の表示も改善しています。

入力後の解析待ちを短くし、長い1行を貼り付けたときの停止に対応しました。4,000文字を超える行とdata URIだけの行は先頭部分だけを表示しますが、全文をコピー・保存できます。

[v1.11.4からの変更点と既知の制限](release_v1.12.58.md)をご覧ください。

## 安全性について(いちばん大事なこと)

このアプリは**完全にオフラインで動作**します。

- **ネットワーク通信を行うコードが存在しません**。AI やクラウドへの送信は一切なく、入力した内容がパソコンの外に出ることはありません。ソースコードを検索して `socket` / `urllib` / `requests` などの通信モジュールが使われていないことを、誰でも確認できます。
- **データはすべてローカルの JSON ファイル**(exe と同じフォルダに作られる vocabulary.json など)に保存されます。メモの内容も語彙も、あなたのパソコンの中にだけあります。
- **グローバルキーボードフックを使いません**。簡易入力ウィンドウの呼び出しキーは Windows の `RegisterHotKey` で**その組み合わせだけ**をOSに予約する方式です（`hotkeys.py`）。`keyboard` や `pynput` のように**全キー入力を監視する仕組みは使っていない**ため、他のアプリの入力を常時監視しません。選択文字の取り込みは、ご本人が簡易入力を呼び出したときだけ行います。この設計はウイルス対策ソフトの誤検知も起こしにくくしています(同じ理由で、exe の圧縮に誤検知の原因となる UPX も使っていません)。
- **使った回数も、いつ使ったかも記録しません**(v1.6.0)。語彙が覚えるのは「その語を書いたことがあるか」だけで、回数・最終使用日時・選び直したときの前後の文章は保存しません。同音異義語は**最後にどの表記を選んだか1つだけ**を覚えます(`last_choice.json`)。
- 補正は**辞書(janome の形態素解析)とローカルの統計**だけで行います。機械学習モデルのダウンロードや外部 API の呼び出しはありません。

## 主な機能

- **再変換**: 確定済みの単語を、いつでも候補一覧から選び直せます。クリックのほか **F2** キーでも開けます。一覧が開いているあいだは **←** **→** で対象の語そのものを前後に移せる(F2 の連打でも1つ左へ遡れる)ので、少し前に書いた語もスムーズに直せます。行の先頭まで来たら前の行の末尾へ続けてたどります。
- **簡易入力ウィンドウ**: **Ctrl+Insert** または **Ctrl+Shift+-** で、他のアプリを使っている最中でも小さな下書き窓を呼び出せます。常に手前に浮くフロートウィンドウなので、他のアプリの前に出たまま書けます。閉じると内容が自動でクリップボードに入るのですぐ貼り付けられ、本体のメモ帳にも送られます。呼び出したモニターのマウス付近に表示し、最小化から戻すときも位置を取り直します。呼び出し元の入力欄のIMEが全角であることを確認できた場合は、その入力モードを引き継ぎます。窓の中でも補正が自動で反映され、選択なしのF1で引用、F2で再変換、F5で括弧の挿入・切替・選択範囲の囲みが使えます。一度候補を選んだ後も選び直せます。
- **自動補正**: 打ち間違いから正しい単語を推測して提案・補正します(直せる誤りの種類は下記)。起動直後の解析中に編集したときも、入力した行を優先して処理します。解析中はウインドウ下部に進み具合を表示し、通常ウインドウでは完了後に隠して本文欄を広げます。最大化中は欄を残します。行番号の右端には、未解析・解析未完了の行だけ薄い茶色の線を付けます。解析が済んだ行の線は消えます。線が消えても、本文や補正の正しさを保証するものではありません。
- **ブックマーク**: 行番号のダブルクリックで行に目印を付け、あとから順にたどれます。移動先を中央に表示し、その後はホイールやスクロールバーで通常どおり先頭まで戻れます。
- **引用モード**: メモの中にある単語をクリックで拾って、カーソル位置に差し込めます。もう一度打ち直す必要も、コピーして貼り付ける手間もありません。**F1**・選択なしの **Ctrl+C**・**=** のどれからでも入れます。整数のみは行番号、**-N**はN行前、**+N**はN行後の行全体をEnterで引用します。`-1+2` のように数値の後ろに演算があれば計算します。
- **選択範囲の文字種**: **F6**で平仮名、**F7**でカタカナ、**F8**で半角、**F9**でJISかな配列の英数字キー列へ変換します。漢字は辞書の読みを使い、読めない文字は残します。簡易入力でも使えます。
- **箇条書き**: 括弧ボタン群の左のボタンで開始し、単語のクリック・範囲のドラッグで拾います。カーソル行の下に空白行を1行挟み、連続して拾った文字を順に並べます。Escか文字入力で終了します。簡易入力の背景色があるときは、区切りごとの文字だけを抜き出して同じ位置から行に分け、モードを終了します。
- **単語帳（4セット）**: ツールバーの「単語帳」から小さな独立ウインドウを開き、「追加」を押して単語をクリック、または範囲をドラッグして登録します。登録した語をクリックするとコピーでき、右クリックから削除できます。「編集」メニューでセット1〜4を切り替えられ、リセットは確認した選択中セットだけに作用します。登録内容・選択セット・表示状態・幅は保存されます。上部の色が付いた帯をドラッグすると窓を移動できます。簡易入力と同じくタスクバーやAlt+Tabから独立して切り替えられ、コピー後は直前に使っていた窓へ戻します。
- **選択文字を簡易入力へ**: 本体で文字を選んで簡易入力を開くと、選択文字を引き継ぎます。他アプリからは簡易入力のグローバルキーで呼び出してください。取得できた選択を既存入力へ追記します。Excelの選択セルはタブ・改行で並べます（実Excelでの確認は継続中）。
- **ファイル履歴**: 「ファイル → 最近開いたファイル」から最近の20件を開けます。すでに開いているタブは未保存の内容を保って再表示します。
- **Undo／Redoの色と慣性**: Undo後は次にUndoで消える文字に、Redo後は復元された文字に、色付き下線を付けます。「表示」メニューでホイールと右ドラッグの慣性を個別に切り替えられ、初期状態は両方オンです。
- **ルーラーとボタン設定**: 横線ボタン（─）で現在の行にルーラーを追加・解除できます。カーソルを動かしてもその行に残り、複数行に設置でき、タブごとに保存します。最終行の線は二重線です。「ボタン」メニューで表示と順序を変更でき、F5は表示中の括弧をその順に切り替えます。
- **リンク**: URLと絶対ファイルパスを青色で表示します。クリックで開き、ドラッグした場合は範囲選択します。空白を含むパスは引用符で囲んでください。
- **一括挿入**: 単語帳の右のボタンから開き、選択した各行の部分に同じ文字列を挿入します。先頭から何文字後、または末尾から何文字前かを指定します。0は指定側の端、文字数を超える指定は反対側の端に挿入します。数値は直接入力、1刻みの上下ボタン、プルダウンで指定できます。「実行を戻す」で直前の一括挿入を取り消せます（別の本文編集やタブ切替後は対象外）。窓の操作中も本文の選択範囲を表示し、挿入する文字と文字の間を縦線で示します。位置の数値や先頭・末尾の指定を変えると、縦線も移動します。本体・一括挿入窓どちらからでもEscで閉じられ、最後の文字列と位置指定は次回起動にも残ります。
- **括弧で括る**: 選択した範囲をボタン1つで「」『』【】“” などの括弧で囲めます。F5でも挿入・種類の切替・選択範囲の囲みができ、F2で語を選んでいるときは、その語を括ります。簡易入力でも共通です。選択内または直外にある対応括弧は差し替え、F5で指定と同じ種類なら次の種類へ進みます。括弧ボタンは指定した種類へ差し替えます。
- **行の選択と画面の移動**: 行番号のクリックやドラッグで行をまるごと選べます。余白を右クリックしたままドラッグすると画面がスクロールします(タッチ画面では1本指でなぞってスクロール)。
- **俯瞰**: 右ボタンをダブルクリックして押したままにすると、文字が一時的に小さくなって広い範囲が一度に見えます。そのまま上下に動かして行き先を探し、離すと元の大きさに戻ります。長いメモの中を一気に移動できます。
- **不自然な文字列の表示**: 日本語として成り立っていないと判断した箇所を紫で見せます。紫が付いた場所が実は正しいときは、右クリック(または **F2**)から **この文字列は正しい(今後、紫を付けない)** と伝えられます(v1.6.0)。補正できた箇所は補正の色に変わるので、**紫のまま残るのは直し先が見つからなかった箇所**です。
- **品詞の判定と補正の根拠**（表示メニュー・既定オフ）: 候補一覧のいちばん下に、選んだ範囲が**どの品詞と判定されたか**（イ形容詞・ナ形容詞の語幹など。活用している語には原形も）と、**なぜ不自然だと見たのか／何をして直したのか**を出せます。辞書に無い語には「(辞書に無い語)」と明記するので、アプリが推測しただけの箇所が分かります。補正の答えそのものは変わりません。
- **見えない空白の表示**: 半角スペース・全角スペース・タブに、行の下端の細い線で印を付けます。連続していても何個あるか数えられます。
- **タブ管理と自動保存**: 複数のメモをタブで開けます。**Ctrl+Tab** / **Ctrl+PageDown** で次のタブ、**Ctrl+Shift+Tab** / **Ctrl+PageUp** で前のタブへ移れます。保存せずにそのまま閉じても、次に開いたときに続きから再開できます。

そのほか、検索・置換(正規表現対応)、ダークモード、直されたくない語の指定、語彙の手動登録などがあります。同じフォルダのアプリが二重に起動しないようになっており(データの保存が競合しないため)、すでに開いていればそちらの窓が前に出ます。

## 自動補正で直せる誤りの種類

- 隣のキーの押し間違い
- 濁点・半濁点の付け忘れや余分
- 「ゃ」「っ」などの小書きの忘れ
- 1文字の打ち忘れ・キーの押しすぎ
- 打つ順番の入れ替わり
- 濁点だけが離れて入力されたもの・濁点が1つ隣にずれたもの
- 場違いな小書き・濁点・伸ばし棒(隣のキーの文字に戻します)
- Shift の押し忘れで大書きになった拗音
- 音便のあとの「た」と「だ」の取り違え(`読んて` → `読んで`)
- 同じ2文字を2回くり返す語の崩れ(`そももそ` → `そもそも`)
- 大文字の略語の押し間違い(`YRL` → `URL`)
- 漢字に変換したあとの誤り(読みに開き直して、本来の入力を探ります)
- 日本語入力をオフにしたまま打った行(かな入力・ローマ字入力とも、半角のまま打った内容を日本語に復元)
- 助詞の打ち忘れ(`静か歩く` → `静かに歩く`)
- 漢字を平仮名に開き戻す向きの直し(`設計の見して` → `設計のみして`)

直すのは「明確に誤りだと言えるもの」だけです。判断がつかない場合はあえて直さず、色を付けて知らせるだけにとどめます。

この版の変更点は [v1.12.58](release_v1.12.58.md) を参照してください。補正精度には未解決の不一致があり、未補正・意図と異なる変換・漢字表記まで完成しない場合が残っています。補正全体検査に合格した版ではありません。

説明書の画像付きガイドは21機能・70手順です。入力中のマウスポインター非表示と、右ドラッグでのスクロールも手順ごとに掲載しています。画像はHTML内に含まれ、オフラインで見られます。

## 使い方

同梱の `CorrectNote_説明書.html` には、操作手順を85枚の実画面で説明したガイドがあります。画像をクリックすると拡大でき、通信なしで読めます。「このアプリについて → 説明書をHTMLで展開」から開けます。

### exe をそのまま使う

[Releases](../../releases) から `CorrectNote.exe` をダウンロードして、好きなフォルダに置いて実行するだけです。Python のインストールは不要です。語彙などのデータファイルは exe と同じフォルダに自動で作られます。

### ソースから実行する

Python 3.9 以降と tkinter(通常は Python に同梱)が必要です。

```
pip install janome
py app.py
```

janome は必須です(無いと補正の主力の守りが働かず、精度が大きく落ちます)。`py check_janome.py` で確認できます。

### 自分でビルドする

```
build_exe.bat
```

をダブルクリックすると、現在のソースから `dist\CorrectNote.exe` を作ります。ローカルのPython 3.9を優先し、別のPythonを使うときは `CORRECTNOTE_PYTHON` に `python.exe` のパスを指定します。PyInstallerとjanomeは事前にそのPythonへ入れてください。ビルド後はEXE内の版・補正コード・同梱語彙を現行ソースと照合し、不一致なら失敗を表示します。GitHub Actionsにもタグからの自動ビルド・公開があります。公開時は操作・起動・保存・単語帳の検査とEXEのソース・同梱物照合を公開条件とし、補正精度の不一致は別の診断として報告します。補正全体の合格を示すものではありません。

## テスト

```
py tests_mock.py
```

janomeの無い環境用のモックテストです。janomeがある環境では未測定として終了します。実辞書・Windows画面の検査は `python ci_smoke_test.py` で実行します。モックの合格と補正全体の合格は別で、未解決の不一致が残っています。Windowsの公開条件は `python release_checks.py` で確認できます。GitHub Actionsの補正モック結果は専用ログと要約に残ります。実辞書の全体診断はActionsの手動実行で追加できます。
