# CorrectNote（かな入力誤字補正メモ帳）

誤字を気にせず、思考の速度でメモが取れることを目指した Windows 用のメモ帳です。かな入力（JIS 配列）での隣接キーの押し間違いなどを、辞書と統計だけを使ってその場で補正します。左の欄に入力すると、右の欄に補正後のテキストが行ごとに対応して表示されます。

## 安全性について（いちばん大事なこと）

このアプリは**完全にオフラインで動作**します。

- **ネットワーク通信を行うコードが存在しません**。AI やクラウドへの送信は一切なく、入力した内容がパソコンの外に出ることはありません。ソースコードを検索して `socket` / `urllib` / `requests` などの通信モジュールが使われていないことを、誰でも確認できます。
- **データはすべてローカルの JSON ファイル**（exe と同じフォルダに作られる vocabulary.json など）に保存されます。メモの内容も学習した語彙も、あなたのパソコンの中にだけあります。
- **グローバルキーボードフックを使いません**。ホットキーはアプリ自身のウィンドウ内でのみ動作する実装で、他のアプリの入力を監視することはありません。この設計はウイルス対策ソフトの誤検知も起こしにくくしています（同じ理由で、exe の圧縮に誤検知の原因となる UPX も使っていません）。
- 補正は**辞書（janome の形態素解析）とローカルの統計**だけで行います。機械学習モデルのダウンロードや外部 API の呼び出しはありません。

## 主な機能

- かな入力の隣接キー誤打・濁点や半濁点の付け間違い・半角での誤打（ローマ字/かなのモード違い）などの自動補正
- 使うほどあなたの語彙を学習（学習内容はローカルの JSON のみ）
- F2 での候補の選び直し（押すたびに左の語へ遡る）、簡易入力窓、引用、タブ管理、ブックマーク、タッチスクロールなど

## 使い方

### exe をそのまま使う

[Releases](../../releases) から `KanaMemo.exe` をダウンロードして、好きなフォルダに置いて実行するだけです。Python のインストールは不要です。語彙などのデータファイルは exe と同じフォルダに自動で作られます。

### ソースから実行する

Python 3.11 以降と tkinter（通常は Python に同梱）が必要です。

```
pip install janome
py app.py
```

janome は必須です（無いと補正の主力の守りが働かず、精度が大きく落ちます）。`py check_janome.py` で確認できます。

### 自分でビルドする

```
build_exe.bat
```

をダブルクリックすると `dist\KanaMemo.exe` ができます（内部で PyInstaller を使用）。GitHub Actions でも `v` で始まるタグを push すると自動でビルドされ、Release に exe が添付されます。

## テスト

```
py tests_mock.py
```

janome の無い環境用のモックテストです（900 件以上）。janome を入れた環境では一部が実機挙動側に寄って NG になりますが、それは想定どおりです。
